1.0 Release Notes

Multiserver: 
- Allow different servers to add OpenPOTD at the same time. 
- Allow custom prefixes to be set. 
- Allow servers to set their own gold/silver/bronze roles. 

Other: 
- Allow people to toggle anonymity on the OpenPOTD website.
- Custom menus implementation works in DMs as well. 
- Added exponential cooldown system for not solving a problem. 
- Add a license (AGPL 3.0).
- Use dateparser module to allow different date formats to be
  parsed.


1.1 Release Notes

Management:
- Allow images to be cleared through the bot


1.2 Release Notes

Slash commands:
- All commands are now Discord slash commands; the command
  prefix has been removed entirely.
- No privileged intents are required any more.
- Answers are still submitted by DMing the bot.

Other:
- Updated to discord.py 2.7 and Python 3.13.
- The /check command now replies ephemerally instead of
  deleting the invoking message.
- /update takes typed options instead of flag-style arguments.
